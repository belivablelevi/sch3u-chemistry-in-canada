# Chemistry in Canada — SCH3U Assignment

A single-page site on two Canadian chemists, Peter Winterburn (exploration geochemist) and
Orlando Aloysius Battista (cellulose chemist), built for an SCH3U assignment.

No build step — plain HTML/CSS/JS.

## Files

- `index.html` — all content
- `styles.css` — design system
- `script.js` — scroll reveals + sticky visual-story sequences
- `images/` — real photos and diagrams, all real/freely licensed (credits in the Sources
  section of the page)

## Preview locally

Open `index.html` directly in a browser, or run:

```
npx serve .
```
